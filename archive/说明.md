# archive/ —— 已退役的一次性脚本（只读存档）

这些是一次性发布 / 测量用的临时脚本，能力已经搬进正式工具或搬进文档，所以从 tools/
与仓库根下线，原件留在本目录备查。

**不要直接运行这里的脚本**：它们依赖当时的本机绝对路径（D:/QUARK/...）、GH_TOKEN
环境变量，以及一个已经改名的远端仓库（LC93476/sdxl-camera-studio）。

| 原件 | 原来干什么 | 为什么下线 | 能力现在在哪 |
|---|---|---|---|
| publish_github.py | 建仓库 / 推 / 用 token 推完写回干净 origin（213 行，带 argparse 与 dry-run） | 发布是一次性动作，脚本里嵌着 token 用法说明，长期留在 tools/ 会被误当公共工具 | 直接 git push；GitHub 侧设置见 README「发布」一节 |
| publish_final.py | 硬编码 owner/name + git push --force + PATCH private=false（把仓库转公开） | 硬编码仓库名与强制推送，误跑会改远端可见性；改名后失效 | 手工 git push，可见性在 GitHub 网页改 |
| recreate_public.py | DELETE /repos/... → 等待 → 重建公开仓库 → 重推（43 行） | 破坏性最高（删仓库重建），且仓库已改名 sdxl-camera-angle | 手工建仓库 + git push |
| tok_measure.py | 用 ComfyUI 的 CLIP-L 分词器量 SDXL_TAGS 每条 tag 的 token 成本（29 行） | 与 tools/token_count.py 重复；后者已有真分词器 + 估算降级，还能当库用 | python tools/token_count.py --vocab（同一张表、同一套分词器） |
| 发布到GitHub.bat | 双击版发布向导，调 tools/publish_github.py | 依赖已下线的脚本；根目录不再放发布入口 | 已从 git 移除，并在 .gitignore 加 /发布到GitHub.bat 防止复发 |

## 想恢复某个能力怎么办

- 量 token：python tools/token_count.py "front view, eye level shot"，
  或用 --file prompt.json、--vocab（词表逐条成本）、--quiet（脚本用）；
  库入口 tools.token_count.run(positive, negative="", parts=None)。
- 发布：git add -A && git commit && git push，token 只在命令行用一次，不要写进脚本。
- 这批脚本要复活：先改硬编码的仓库名与本机路径，再加回 tools/，并删掉本说明里对应的行。
